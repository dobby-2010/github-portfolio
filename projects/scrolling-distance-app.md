# Scrolling Distance App — Doomscroll

**Argos Inc portfolio member · iPhone-first concept · planning stage**

This project is the scrolling-distance idea currently described under the working product identity **Doomscroll**. The parent portfolio is Argos Inc; the app retains an independent visual identity. **No separate app-source repository or functioning iPhone tracking implementation has yet been located.**

## Concept and design

- [Product specification and change-control decisions](doomscroll/CONCEPT.md)
- [Browsable three-view iPhone mockup](doomscroll/mockup.html)
- [Research / cited iOS technical references](doomscroll/RESEARCH.md)
- [Argos 82-rule / Apple Design review](doomscroll/DESIGN_REVIEW.md)

**What the user wants:** an automatically reconstructed, cross-app, Strava-style activity journal for doomscrolling on iPhone. Selected Instagram, TikTok, Reddit and other app use should form sessions without manually pressing Start/Stop or recording each session. The primary metric is **estimated screen-equivalent scroll distance**, made comprehensible with giraffe, Eiffel Tower and other real-world comparisons. Sessions/history and an app-level breakdown are secondary goals.

**Critical technical limitation:** no documented public iOS API lets a third-party App Store app read Instagram/TikTok raw touch coordinates or content-scroll movement. Screen Time-based duration modelling and optional user-configured Shortcuts app-open/app-close triggers need real-device feasibility testing. **No exact distance or automatic session accuracy is established.**

**Design:** editorial illustration and measured humour; no generic AI dashboard. Product-specific colours, typography and identity. Concept labels mock data and uncertainty. Do not replace or recreate the approved original **Argos Inc engraved oval emblem**—the binary source is not in this repo.

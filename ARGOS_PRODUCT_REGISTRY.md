## Onboard the two new projects
1. Identify the existing source/code, website or repository. Do **not** create duplicate apps by guessing.
2. Confirm app name, functionality, platform, data protection requirements and intended audience.
3. Add `AGENTS.md`, an appropriate copy/link of `ARGOS_DESIGN_PRINCIPLES.md`, and pinned `.agents/skills/apple-design/SKILL.md` with MIT licence and source attribution.
4. Preserve each app's colours and identity. Plan changes as reviewable code changes.
5. Build a proof-based portfolio entry only after functionality and source are verified.

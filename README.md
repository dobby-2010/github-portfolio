# Argos Inc

**An independent portfolio of software, engineering and analytics projects.**

Argos Inc is the umbrella—not a universal design skin. Each project keeps its own product name, personality, interface and source code. What all projects share is thoughtful engineering and a professional UI quality standard.

## Shared design engineering

**[Argos Design System v0.7](argos-design-system/ARGOS_DESIGN_PRINCIPLES.md)** is the shared standard for hierarchy, spacing, typography, accessibility, responsive behaviour, data displays and fine UI craftsmanship.

**[Apple Design Interaction Principle](argos-design-system/APPLE_DESIGN_ADOPTION.md)** is now a standing interaction-design review standard: immediate feedback, intuitive direct manipulation, interruptible gesture motion, spatial coherence, user agency, accessible alternatives and purposeful animation. Each app keeps its own look; this is not a mandate to imitate Apple's interface.

Also see [original screenshot rules](argos-design-system/SCREENSHOT_SOURCE_AUDIT.md), [implementation playbook](argos-design-system/UI_IMPLEMENTATION_PLAYBOOK.md), [UI quality checklist](argos-design-system/UI_QUALITY_CHECKLIST.md) and [full product registry](ARGOS_PRODUCT_REGISTRY.md).
